# Card Desk Drops

A personal PWA that tracks trading-card drops for football, Formula 1 and English-language Pokémon TCG. It ranks them against the owner's buying rules and alerts before watched drops go live.

The brief is in [`docs/brief.md`](docs/brief.md) and the project conventions are in [`CLAUDE.md`](CLAUDE.md).

Status: Phase 1 (MVP) is built. To deploy it, see [`docs/deploy.md`](docs/deploy.md).
